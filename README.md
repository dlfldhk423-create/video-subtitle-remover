# 🎬 AI Video Subtitle Remover Studio (비디오 자막 삭제 프로그램)

> **GitHub 오픈소스 기반의 강력한 AI 텍스트 마스킹 & 비디오 인페인팅(Inpainting) 기술**을 결합하여, 동영상에 박혀있는 하드서브(Hardcoded) 자막이나 워터마크를 주변 배경 훼손 없이 깨끗하게 제거하고 원본 고음질 오디오를 그대로 유지해주는 웹 스튜디오 프로그램입니다.

## ✨ 주요 기능 및 특징

1. **드래그 앤 드롭 웹 UI (Web Studio)**
   - 브라우저(`http://localhost:8000`)에서 간편하게 영상을 업로드하고 직관적으로 조작 가능
   - MP4, MOV, MKV, WebM, AVI 등 모든 주요 동영상 포맷 지원

2. **인터랙티브 자막 영역 지정 & 프리셋 지원**
   - 비디오 화면 위를 마우스로 직접 드래그하여 원하는 자막 위치(ROI)를 손쉽게 박스로 지정
   - `하단 자막`, `하단 와이드(2줄)`, `상단 제목` 등 원클릭 프리셋 제공
   - 타임라인 슬라이더를 통해 자막이 등장하는 프레임으로 바로 이동하여 정밀하게 영역 확인 가능

3. **3가지 제거 모드 지원**
   - **✨ 스마트 텍스트 모드 (AI 추천)**: 적응형 임계값, 색상 역치, 엣지 감지를 통해 **배경은 그대로 보존하고 글자 픽셀만 감지**하여 지우므로 결과물이 매우 자연스럽습니다.
   - **🔲 영역 전체 복원 모드**: 박스 영역 전체를 주변 텍스처로 매끄럽게 채웁니다.
   - **💧 스마트 블러 모드**: 자막 영역을 자연스럽게 모자이크/블러 처리합니다.

4. **초고속 0.1초 프레임 실시간 미리보기**
   - 전체 영상을 렌더링하기 전에, 현재 프레임에서 자막이 얼마나 깨끗하게 지워졌는지 **미리보기 이미지** 및 **AI 마스크 감지 화면**으로 0.1초 만에 확인 가능

5. **실시간 렌더링 진행률 (ETA / FPS)**
   - 처리 프레임 수, 진행률(%), 초당 처리 속도(FPS), 남은 예상 시간(ETA)을 실시간으로 안내

6. **원본 오디오 무손실 보존 & 소프트 자막 스트림 완전 제거**
   - FFmpeg H.264 인코딩을 통해 원본 비디오의 고음질 오디오(AAC 등)를 100% 무손실 결합
   - 컨테이너 내부의 소프트 자막 스트림(`-sn`)도 함께 제거하여 완벽한 무자막 영상 생성

## 🚀 빠른 시작 방법 (How to Run)

### 방법 1. Mac 환경 원클릭 실행 (추천)
터미널에서 아래 명령어를 실행하면 가상환경 확인 후 브라우저가 자동으로 열립니다.

```bash
./run.sh
```

### 방법 2. Windows PC 환경에서 실행
- **방법 A (GitHub 자동 빌드 EXE 사용)**: 깃허브 저장소의 `Actions` 탭에서 빌드된 `SubtitleRemover-Windows-x64.zip`을 다운로드하여 압축을 풀고 `SubtitleRemover.exe`를 더블클릭합니다.
- **방법 B (Python 환경 원클릭 실행)**: `run_windows.bat` 파일을 더블클릭하면 자동으로 가상환경 설치 후 웹 브라우저가 열립니다.
- **방법 C (직접 EXE 빌드하기)**: `build_exe.bat` 파일을 더블클릭하면 `ffmpeg.exe` 자동 다운로드 및 PyInstaller 컴파일을 거쳐 `dist\SubtitleRemover\SubtitleRemover.exe`가 생성됩니다.

## 👵 시니어 & 초보자 분들을 위한 3초 초간단 사용법 (글씨 크게 보기)

> 복잡한 컴퓨터 설정을 모르셔도 괜찮습니다! 아래 순서대로 **딱 3번만 클릭**하시면 영상의 자막이 말끔하게 사라집니다.

```
[1단계] 동영상 올리기   ➡️   [2단계] 하단 자막 누르기   ➡️   [3단계] 지우고 저장하기
  (파란 버튼 클릭)             (빨간 상자 자동 맞춤)             (초록 버튼 클릭)
```

### 1단계: 동영상 올리기 📁
- 화면 가운데에 있는 파란색 **[영상 파일 선택]** 버튼을 꾹 누르고, 내 컴퓨터나 스마트폰에 있는 동영상을 골라주세요.
- *(처음이라 시험삼아 연습해보고 싶으실 때는 바로 옆의 **[🎬 샘플 영상으로 즉시 체험]** 버튼을 누르시면 준비된 연습 영상이 짠 나타납니다!)*

### 2단계: 자막 자리 누르기 🎯
- 영상이 화면에 나오면, 오른쪽 위에 있는 **[하단 자막]** 버튼을 한 번 콕 눌러주세요.
- 영상 속 자막 자리에 **빨간색 네모 상자**가 자동으로 딱 맞춰집니다.
- *(자막이 두 줄이거나 위쪽에 있을 때는 [하단 와이드]나 [상단 제목]을 누르셔도 되고, 마우스로 화면을 직접 드래그하셔도 됩니다)*

### 3단계: 지우고 내 컴퓨터에 저장하기 🚀
- 화면 오른쪽 아래에 있는 큰 초록색 **[전체 영상 자막 삭제 시작]** 버튼을 꾹 누릅니다.
- 진행률이 차오르면서 `100%`가 되면 자막이 싹 지워진 깨끗한 영상이 나타납니다.
- 아래에 생기는 큰 초록색 **[완성된 비디오 다운로드 (MP4)]** 버튼을 누르면 내 컴퓨터/폰에 저장됩니다.
